# 内置模型管理指南

## 概述

> 同为内置系统配置的还有 [内置MCP服务管理](内置MCP服务管理.md)

## 如何添加内置模型

### 1. 准备模型数据

- 模型名称（name）
- 模型类型（type）：`KnowledgeQA`、`Embedding`、`Rerank` 或 `VLLM`
- 模型来源（source）：`local` 或 `remote`
- 模型参数（parameters）：包括 base_url、api_key、provider 等

**服务商预设（provider）**：`generic`、`openai`、`anthropic`、`deepseek`、`aliyun`、`zhipu`、`moonshot`、`siliconflow`、`volcengine`、`openrouter`、`gemini`、`ollama`。预设按模型类型筛选，其他兼容服务可使用 `generic` 并填写地址。

对话使用 OpenAI 兼容、Anthropic 原生或 Ollama。嵌入使用 OpenAI 兼容或 Ollama，阿里云文本嵌入默认地址为 `https://dashscope.aliyuncs.com/compatible-mode/v1`。重排使用通用 `/rerank` 格式或阿里云百炼，Jina 等兼容服务使用 `generic`。Gemini 使用 `https://generativelanguage.googleapis.com/v1beta/openai/`。

完整 YAML 配置与 SQL 示例见 [内置模型管理指南](../../BUILTIN_MODELS.md)。

### 2. 执行 SQL 插入语句

```sql
-- LLM 内置模型
INSERT INTO models (
    id, tenant_id, name, type, source, description, parameters,
    is_default, status, is_builtin
) VALUES (
    'builtin-llm-001', 10000, 'GPT-4', 'KnowledgeQA', 'remote',
    '内置 LLM 模型',
    '{"base_url": "https://api.openai.com/v1", "api_key": "sk-xxx", "provider": "openai"}'::jsonb,
    false, 'active', true
) ON CONFLICT (id) DO NOTHING;

```

### 3. 验证

```sql
SELECT id, name, type, is_builtin, status
FROM models WHERE is_builtin = true ORDER BY type, created_at;
```

## 注意事项

1. **ID 命名规范**：建议使用 `builtin-{type}-{序号}` 格式
2. **参数格式**：`parameters` 字段必须是有效的 JSON 格式
3. **幂等性**：使用 `ON CONFLICT (id) DO NOTHING`
4. **安全性**：API Key 在前端会被自动隐藏

## 模型配置与常见问题

- 如果 Embedding 模型未正确配置，会导致文档无法上传。排查步骤参见 [常见问题](../运维排障/常见问题.md)
- 模型参数中的 `provider` 决定了 API 调用格式和认证方式
