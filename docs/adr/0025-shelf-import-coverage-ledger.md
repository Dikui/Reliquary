# 0025 货架表格导入的无损盘点与覆盖账本

Status: proposed
日期：2026-11-14
修订：[产品货架表格导入](../product-shelf-import.md) 中“仅有表头的列不产生反馈”与“表头行按方案跳过、不反馈”的规则；未映射列反馈本身不变。

## 决策

导入分三层，只有货架一侧的目标结构是固定的：

1. **盘点层**：读取工作簿时保留每个单元格的值、公式、底色、删除线、非默认字体颜色、批注、超链接地址，以及行、列、工作表的隐藏状态和绘图对象。这一层不理解业务。
2. **规则层**：方案的每张工作表可以给出 `range`（表格所在区域）和 `transpose`（记录按列排列）。导入前把区域按方向整理成以记录为行的虚拟表，再交给现有的各文件种类解析器；来源位置始终换回原单元格。目标字段仍只能取各文件种类的固定字段。
3. **覆盖账本**：解析后，服务端对每张已映射工作表的每个有内容或有标记的原单元格判定去向：已由映射读取、已在未映射列反馈中列出、或未覆盖。未覆盖内容按工作表、原因和列分组生成 `import_notice`，冲突类型为 `uncovered_content`。它阻止“应用”：提交方只能明确放弃（确认不导入）或暂缓（问客户）。被忽略的工作表若有内容，同样生成一条未覆盖提示。

未覆盖的原因：`outside_range`（区域外）、`header_area`（表头区内既不是已映射列表头、也不是未映射反馈列表头的内容，如标题、图例）、`format_only`（只有底色或字体标记、没有文字的单元格未被解析器读取）、`strike`（删除线）、`font_color`（非默认字体颜色）、`comment`（批注）、`hyperlink`（超链接地址）、`hidden`（隐藏行列中的内容）、`hidden_sheet`、`drawing`（图片、图形）、`ignored_sheet`。

## 取舍与验证

还没有客户真实表格。为假想布局逐个写解析器大概率猜错，兼容所有表格也做不到；能保证的是任何内容都不被静默跳过。因此不新增文件种类，而是把输入形态（区域、方向）和目标字段分开，并用账本强制每处内容有去向。

账本按“工作表 + 原因 + 列”分组，避免逐格提问并受 500 项批次上限约束；代价是同组内容只能一并放弃或暂缓。字体颜色只在与工作簿默认字体不同时计入，减少噪声。删除线、批注、超链接等不会被解释成业务含义，只要求提交方知情并决定；需要导入时由用户给出含义后通过单项操作补写。

一张工作表仍只对应一份映射；同表多块表格先由提交方在本地拆分临时副本，区域外的块会以 `outside_range` 出现，不会被静默丢弃。

验证用代码构造的脱敏“刁难表”：转置、区域外说明、表头上方图例、删除线、批注、超链接、隐藏行、只有底色的格子、被忽略但有内容的工作表。每份表的未覆盖内容都必须出现在提示中，且未决定前批次不能确认。
