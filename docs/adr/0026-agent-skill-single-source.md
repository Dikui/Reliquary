# 0026 技能包是 agent 规则与流程的唯一来源

Status: accepted
日期：2026-11-14

## 决策

Agent 使用规则和多步流程的正文只放在仓库的技能包 `skills/reliquary/`，由同目录的 Go 嵌入包在编译时嵌进程序。MCP 服务把规则文件原样作为握手的 `instructions` 返回，把流程文件原样由只读工具 `reliquary_guide` 返回；嵌入文件读取失败时服务启动失败，不降级为空说明。装了技能包的 agent 与只连 MCP 的 agent 读到同一份文字。

## 取舍与验证

服务端说明与技能包分开维护会出现两套说法，因此只留一份正文。流程通过工具下发，而不用 MCP prompts 或 resources：所有 MCP 客户端都支持工具，后两者的客户端支持参差不齐。代价是正文改动后须重新构建并部署服务端，技能包副本须用户重新复制或使用软链。

测试经真实 MCP 端点验证 `instructions` 与嵌入规则文件一致、每个流程都能通过 `reliquary_guide` 读到，并要求技能文件中以反引号写出的工具名都出现在 tools/list 中，防止技能悄悄过时。
