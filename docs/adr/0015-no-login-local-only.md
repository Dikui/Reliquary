# 0015 去掉登录，只允许本机访问

Status: accepted
部分取代 [0007](0007-personal-single-user.md)（注册、登录、修改密码、重置密码命令）
日期：2026-10-15

## 背景

系统只有一个用户，并且只在自己的电脑上使用。每次打开网页都要登录，令牌过期后还要刷新，还要维护注册、修改密码和重置密码命令，这些成本没有换来实际保护。

## 决策

- 删除注册、登录、令牌刷新、退出、修改密码接口和页面，删除 `reset-password` 命令和 `JWT_SECRET`。
- 不带凭据的请求直接作为唯一用户。第一次请求时如果还没有用户，就自动创建一个。
- 只允许本机访问：服务默认监听 `127.0.0.1`，Docker 端口只绑定到宿主机的 `127.0.0.1`。
- 不带凭据的请求还要满足两个条件，用来防止其他网站借用浏览器访问本机服务：
  - Host 必须是 `localhost` 或回环地址（防 DNS rebinding）；
  - 浏览器的 `Sec-Fetch-Site` 不能是 `cross-site`（防 CSRF 和跨站读取）。
- API Key 保留。外部工具和 MCP 继续使用 API Key，`/mcp` 不接受无凭据请求。

## 后果

- 打开网页即可使用，不再有登录过期。
- 同一局域网的其他设备不能访问。以后要远程使用时，要先重新引入认证，再放开监听地址，不能只改端口绑定。
- `auth_tokens` 表原先保留历史记录；结构版本 48 起，按 2026-10-26 的补充决策删除。
- 用户名和邮箱固定为自动创建时的值（`me`、`me@localhost`），已有用户保持原值。

## 2026-10-26：清理账号与辅助入口

- 删除界面中的头像、用户名、邮箱和用户资料页。侧栏保留设置入口，继续访问工作区、模型和系统配置。
- 删除 `/auth/me` 和浏览器登录状态，工作区初始化使用现有 `/space`。
- 主题、字体和最近搜索按本机保存。升级时迁移旧账号偏好，保留已有值。
- 删除帮助文档、仓库、配置指南、故障排查文档及提交 Issue 的界面外链；保留错误详情、模型用量管理和资料来源链接。
- 管理脚本不再生成或传递 `JWT_SECRET`。ChatGPT 身份校验使用的 JWT 库继续保留。
- 唯一用户 ID 与空间归属继续供初始化和操作记录使用，不删除业务数据。

### 登录数据结构清理

2026-10-26 经用户确认，迁移 `000048_remove_login` 删除已停用的 `auth_tokens` 表与 `users.password_hash` 字段。唯一用户、工作区、业务资料、API Key、资源访问令牌和 ChatGPT 凭据保持原样。

新导出不再包含这两项。旧备份仍可读取，导入当前版本时丢弃旧登录令牌与密码哈希，其余数据继续严格核对。开发用 down 只重建空表和空密码字段，不恢复被删除的值；生产恢复仍依赖操作前已有的完整备份。
