# 0022 产品库的关联与演进

Status: accepted
日期：2026-11-06
修订：[0021 库级人工维护实体](0021-managed-entity-library.md)。

## 决策

产品实体仍归属一个人工维护库；文献可以放在同一空间内的其他库。文献库通过 `product_library_ids` 选择自动匹配的产品库，普通库继续抽取自己的实体。自动关联只接受正文中的唯一名称、代码或别名，不改写产品资料。手工关联不要求先配置自动匹配。

文献与产品的关联增加 `relation_type`。产品库用 `document_relation_types` 配置可选类型，默认包括涉及、规格书、测试报告和对比评测。自动关联使用 `references`；其他类型由人工指定。每个文献与产品组合保留一个类型以及原有排除决定。重新处理不覆盖人工决定。

产品关系增加 JSON 属性。每个关系类型用 `fields` 定义自己的字段。产品与关系共用字段校验，支持文本、数字、布尔、日期、单选、多选、文本列表、产品引用、HTTP(S) 链接和附件。引用按同一空间校验；附件复用文件存储与资源登记，单文件最多 32 MiB。历史仍可引用的附件不会因清空当前字段而删除。

`entity_attribute_versions` 保存完整属性快照、业务生效时间和记录时间。按指定时间选择最新已生效快照，同一生效时间取较大修订号。未来快照到时生效，读取时计算。查询早于最早快照返回未知；完整快照会整体替代当时的属性。名称、类别、归档状态和关系仍是当前状态，并不承诺按时间回放。已有或历史数据使用的字段不能改成不兼容定义，可归档。

合并在同库内进行：保留目标 ID，显式提供合并后的属性，迁移文献与关系，来源归档并记录目标。拆分保留原实体，创建新实体，仅迁移明确选择的文献关联和关系。两者记录来源链，原有属性时间线留在原实体。来源的未来属性快照不自动转给目标。重复关系、相反的文献关联决定、自环和非法层级会拒绝整个事务。结构调整立即执行；请求中的生效时间仅作用于结果属性，不得为未来时间。

已有文献的库可以转换为人工维护。转换前展示数量，并要求将每种已有实体类型映射到一个库内类别。实体 ID、原存储类型、文献和关系保留；已有文献关联转为人工决定，转换时为属性建立基线。新建的人工实体仍使用 product 存储类型。转换与入库写入共用锁，避免旧抽取任务继续改写产品目录。

## 持久化与验证

迁移 38 增加字段及属性历史、重组记录、附件登记表。旧人工实体最后保存的快照是最早已知状态，不反推更早状态。普通文献的归属不迁移。新数据进入已有导出、恢复与校验流程；独立 Markdown 导出使用精确实体 ID 保存跨库关联，不能用名称猜测恢复。含新增业务数据时拒绝降级。

验证覆盖跨库且带类型的关联、自动匹配与人工排除保留、关系属性、五种新增字段、附件下载、已有库转换、属性时间查询、合并拆分的事务回滚，以及升级和导出恢复。
