# 0016 实体、关系和主题按库独立

Status: accepted
日期：2026-10-28
替代：[0002 跨库统一实体](0002-global-entity-registry.md)；修订 ADR 0014 的实体与主题归属。

## 决策

每个库独立维护实体档案、别名、关系及关系类型、主题目录。同名实体与主题可以在多个库存在，分别拥有 ID；修改、归并和删除不影响其他库。

实体与关系仍开放抽取，须符合类型、相关性和原文证据规则。实体匹配、候选召回、别名冲突和合并都只在本库内进行。关系两端必须属于关系所在库。

主题由用户在一个库内建立。模型只能选择该库已有主题，可多选或为空。主题不能换库，也不能关联其他库的资料。内容类别配置与多模态向量规则保持不变。

## 历史数据

迁移 33 按原资料及关系归属拆分共享实体。关联的别名、关注、合并记录和主题归属同步复制或改指向。没有资料关联的实体复制到已有库，保留人工档案。主题按旧适用库和已有资料关联库拆分。每项记录在排序第一的库保留原 ID，其余副本使用确定性 ID。

已拆分主题的活动历史归入任务停止，旧任务和批次保留，避免继续执行跨库输入。正文、图片、摘要和向量不重算；已有向量随实体副本保留。图谱节点通过待同步记录刷新。

没有可归属库时停止迁移，不删除记录或自动新建库。旧版可移植副本使用相同转换。数据库降级不能合并已经独立的同名档案；生产回退遵循完整备份恢复规则。

## 验证

验证同名实体、别名及主题能分别存在，跨库合并和关联被拒绝；验证迁移前后正文、向量、人工说明、关系证据和关注保留，并核对旧副本导入。数据库约束与服务层校验共同限制跨库关系。
