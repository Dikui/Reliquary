# 0020 前端用无样式组件和自写样式替换 TDesign

Status: accepted
日期：2026-10-28

## 决策

前端沿用 Vue 3、vue-router、Pinia、vue-i18n 和现有 api 层，移除 TDesign。弹窗、抽屉、下拉菜单、组合框、标签页、提示和焦点管理用无样式组件库 Reka UI（锁定精确版本）；外观全部按瑞士信息设计风格自写，设计变量集中在 `frontend/src/styles/tokens.css`，共用组件在 `frontend/src/components/ui/`。表单控件优先用原生元素。不引入其他 UI 库、CSS 框架或图标库。

原因：TDesign 的默认外观、圆角阴影和内部行为难以覆盖到目标风格，且有无法从外部修复的组件缺陷（如可筛选选择框回车无效、键盘操作报错）。完全自写则需自己承担焦点锁定、组合框键盘等可访问性细节；Reka UI 只提供行为、不带样式，能同时满足这两点。

## 放弃的方案

- 保留 TDesign 只换皮：覆盖范围大、与组件内部样式相互抵消，组件缺陷仍在。
- 全部自写交互：依赖最少，但弹层焦点、组合框等边角问题要自己维护。
- 新建独立前端工程整体切换：要重写 api 层与状态，周期最长，迁移期两套界面无法共存验证。

## 约束

- 视觉规则：黄色只标当前焦点项；勾选用浅灰；库用 8 色色块，颜色存数据库、可在库设置修改；无圆角无阴影（浮层除外）；链接黑色下划线。
- 应用根字号保持 14px，设计变量的尺寸用 px 表达，页面样式不使用 rem。
- 后端不支持的功能不在界面占位。
- 设计稿保存在本地 `design/`（不提交）。
