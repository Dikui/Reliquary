# 团队空间权限

系统使用一个团队空间，数据库租户 ID 固定为 1。启动时创建团队，首个注册账号成为 owner 和系统管理员，后续账号通过团队邀请链接注册。

| 角色 | 对应名称 | 权限 |
| --- | --- | --- |
| owner | 创建者、管理员 | 管理团队，转让所有权，管理成员与邀请，查看和编辑全部知识库与智能体 |
| admin | 管理员 | 管理团队配置及成员，查看和编辑全部知识库与智能体 |
| contributor | 编辑者 | 查看全部知识库与智能体，创建和编辑内容 |
| viewer | 只读者 | 查看全部知识库与智能体，检索与问答 |

知识库和智能体属于团队。`creator_id` 仅记录创建者，不限制查看或编辑。会话仍按用户或机器 principal 隔离；用户环境变量及资源收藏属于用户偏好。

系统管理员独立于团队角色，负责系统设置、运行队列和审计日志。团队 API Key 保留检索、入库和完整权限范围，支持限制知识库范围；API Key 的权限由独立的路由授权规则检查。

成员角色存放在 `tenant_members`。移除成员会撤销其会话，保留账号中的固定团队 ID。最后一位 owner 不能被删除或降级，所有权转让需要保留 owner。

角色与成员操作记录在 `audit_logs`。知识库活动通过 `scope_type=knowledge_base`、`scope_id=<kb_id>` 使用同一审计表，团队成员可以读取知识库活动。活动详情不保存正文、外部凭据或原始错误堆栈。
